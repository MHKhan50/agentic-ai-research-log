# MemTrust-Lite Kaggle Dataset

This upload contains a synthetic benchmark for testing the trade-off between agent-memory poisoning resistance and benign task utility under three simple retrieval policies. All data are generated by a deterministic local Python script; no real users, private logs, or third-party dataset rows are included.

**Do not generalize these results to real LLM agents.** The dataset is a simulator for education and reproducibility, not a deployed-agent safety certification.

Files: `scenarios.csv`, `results.csv`, `summary.csv`, `seed_summary.csv`, `DATA_LICENSE.md`, `REFERENCES.md`, `REPRODUCIBILITY.md`, and `DATASET_DESCRIPTION.md`.
